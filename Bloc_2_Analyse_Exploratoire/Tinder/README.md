# Bloc 2 — Speed Dating & Tinder (EDA)

## 🎯 Objectif du Projet
Analyser les déterminants de l'attraction et du match lors de sessions de speed dating (expérience de l'université de Columbia sur 551 participants et 8 378 rencontres). Déterminer si les critères déclarés avant les rendez-vous correspondent aux choix réels lors des décisions.

## 🛠️ Stack Technique
- **Analyse de Données :** Python, Pandas, NumPy.
- **Visualisation & Statistiques :** Seaborn, Matplotlib, Plotly (analyses univariées, bivariées et corrélations).

## 📂 Contenu du Dossier
- `Tinder_speed_dating.ipynb` : Notebook d'analyse exploratoire exhaustive avec nettoyage et tests d'hypothèses.
- `Tinder_presentation.pptx` : Support de présentation officiel (soutenance 5 min).
- `Speed_dating_data.csv` : Jeu de données complet des sessions de speed dating.
- `Speed_dating_data_key.doc` : Dictionnaire des 195 variables du dataset.
