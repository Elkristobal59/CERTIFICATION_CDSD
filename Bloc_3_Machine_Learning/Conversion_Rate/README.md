# Bloc 3 — Challenge Taux de Conversion E-commerce

## 🎯 Objectif du Projet
Prédire si un utilisateur visitant un site d'information / e-commerce va s'abonner / convertir (problématique de déséquilibre de classes et optimisation du F1-score).

## 🛠️ Stack Technique
- Logistic Regression, Random Forest, XGBoost, GridSearch, Métriques F1-score / ROC-AUC.

## 📂 Contenu du Dossier
- `Conversion_rate_prediction.ipynb` : Notebook de modélisation et optimisation des hyperparamètres.
- `Conversion_rate_presentation.pptx` : Support de présentation officiel (soutenance 5 min).
- `conversion_data_train.csv` / `conversion_data_test.csv` : Données d'entraînement et de test.
