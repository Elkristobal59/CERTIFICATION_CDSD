# Bloc 3 — The North Face : Système de Recommandation E-commerce

## 🎯 Objectif du Projet
Construire un moteur de recommandation basé sur le contenu pour suggérer des articles similaires à partir des descriptions textuelles des produits du catalogue The North Face.

## 🛠️ Stack Technique
- NLP (TF-IDF, Tokenization, Stopwords), Similarité Cosinus, Clustering non supervisé.

## 📂 Contenu du Dossier
- `North_face_ecommerce.ipynb` : Notebook complet de vectorisation textuelle et recommandation de produits.
- `sample_data.csv` : Catalogue des produits The North Face avec descriptions.
