# Bloc 3 — Machine Learning Supervisé & Non-Supervisé

Ce dossier regroupe les 3 projets de Machine Learning de la certification :
1. **North Face (Recommandation & NLP) :** Moteur de recommandation e-commerce par similarité cosinus.
2. **Conversion Rate (Classification Supervisée) :** Détection d'abonnements et maximisation du F1-score avec XGBoost / Random Forest.
3. **Walmart (Régression Supervisée) :** Prédiction des ventes avec régularisations Ridge et Lasso.
