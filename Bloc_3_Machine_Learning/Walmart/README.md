# Bloc 3 — Walmart : Prédiction des Ventes Hebdomadaires

## 🎯 Objectif du Projet
Prédire le chiffre d'affaires hebdomadaire des magasins Walmart à partir de variables économiques et climatiques (température, prix du carburant, chômage, IPC).

## 🛠️ Stack Technique
- Scikit-Learn, Régression Linéaire, Régularisation Ridge / Lasso, Validation croisée.

## 📂 Contenu du Dossier
- `Walmart_sales_prediction.ipynb` : Notebook complet de modélisation prédictive.
- `Walmart_store_sales.csv` : Données historiques des magasins.
